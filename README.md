# Pulse

Um monitor minimalista de uptime escrito em Go.

## O Projeto

O Pulse nasceu como um projeto de monitoramento de URLs, tipo o UPTIME KUMA, minha ideia é refazer ele utilizando minhas lógicas e algumas features que eu gostaria que tivessem no rpojeto original

## Funcionalidades

- Monitoramento de status de URLs (HTTP 200)

## Como rodar localmente

```bash
go run main.go
```
