# Pulse

Um monitor minimalista de uptime escrito em Go.

## O Projeto

O Pulse nasceu com um objetivo pessoal claro: voltar às raízes da programação pura. A ideia é construir uma ferramenta funcional escrevendo a lógica na mão, entendendo cada engrenagem do processo e usando IA apenas como documentação de apoio, não como geradora de código.

## Funcionalidades

- Monitoramento de status de URLs (HTTP 200)

## Como rodar localmente

```bash
go run main.go
```
